# Link geography

## Goal

Place archive and entity records using the most specific geography available.

## Prefer this order

1. **Property** — when a known building or land tract is involved (primary sources can link **Associated Properties**).
2. **Location** — village or named place (Paoli, Berwyn), which always has a parent township.
3. **Township** — only when nothing more specific is known. Every township belongs to a county.

## Steps by document type

### Primary source

1. If the notice concerns a known property, set **Associated Properties**.
2. Otherwise set **Township**. The township field is hidden when properties are linked.

### Historical image or property

1. Set **Specific Location** when you know the village/place.
2. Otherwise set **Township**. Township hides once a location is set.

### Research article

1. Add one or more **Townships** for the research article’s geographic scope.

### Business or organization

1. Under **Place**, set **Associated Properties / Sites** to the buildings or tracts the firm or group occupied.
2. Put village, township, and map pins on those **property** documents—not on the business or organization.

### County entity

1. Create under **Taxonomies & Entities → Counties**.
2. Set a unique name (e.g. Chester, Delaware).

### Township entity

1. Create under **Taxonomies & Entities → Townships**, or from a County document’s **Townships** list.
2. Set name and required parent county.

### Location entity

1. Create under **Taxonomies & Entities → Locations**.
2. Set name and required parent township.

## Field notes

- Geography cascades: location → township → county; property can carry location or township.
- Businesses and organizations do not have their own map pin or village field; link properties under **Associated Properties / Sites**.
- Create counties, townships, and locations under Taxonomies before linking them from archive documents.
