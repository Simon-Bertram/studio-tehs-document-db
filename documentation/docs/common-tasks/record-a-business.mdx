# Record an organisation

## Goal

Capture a historical organisation—including commercial businesses, civic groups, and institutions—with type, owners, years active, and the property sites it occupied.

## Property vs organisation

- Create a [property](./model-a-property.mdx) for the physical site first when the building or tract is known.
- The organisation document is the *company, congregation, or civic group*, not the building.
- Do **not** invent a property type for “organisation”—classify the site on the property (e.g. Institutional for a library or fire hall), then link the property from this organisation under **Associated Properties / Sites**.

## Organisation type vs Subject Categories

- **Organisation type** = classification on this document (civic / commercial / institutional).
- **Subject Categories** such as Businesses or Organizations = themes for [tagging archive clippings and photos](./tag-with-categories.mdx). They are not set on organisation documents.
- Use Organisation type here; use categories only when cataloging primary sources or historical images.

## Steps

1. Open **Taxonomies & Entities → Organisations**.
2. Choose the list that matches the organisation:
   - **Commercial / Industrial** — mill operators, lumber yards, water companies, silica/ore firms
   - **Civic / Community** — fire company, library, conservancy, church congregation, horse show
   - **Institutional** — Lincoln Institution, military units as operators
   - **All organisations** — every organisation regardless of type (use when browsing or when type is unclear)
3. Create a new document from that list. Creating from Commercial, Civic, or Institutional **presets Organisation type** for you.
4. Set **Organisation Name** (required).
5. Confirm or change **Organisation type** if needed. Changing type moves the document between the filtered lists.
6. Optionally set **Migration Mapping Key** to the legacy CSV keyword (e.g. `Lincoln` for the Lincoln Institution). This field is visible during migration so you can fill keys; hide it after cutover.
7. Optionally add **Description** and **Years Active** (freeform, e.g. `1870–1920`).
8. Link **Owners / Operators** to Historical Person documents.
9. Under **Associated Properties / Sites**, reference one or more **Properties** (not villages—put geography on the property). This is the single source of truth for organisation↔site links.
10. Publish when ready.

## Field notes

- Create person and property entities first if they do not already exist.
- Places of business or worship are property references only.
- Documents without an Organisation type appear only under **All organisations**, not in the typed lists.
- **Migration Mapping Key** maps CSV keywords onto this organisation during import. Entity keywords like `Lincoln` belong here, not on a Subject Category.
