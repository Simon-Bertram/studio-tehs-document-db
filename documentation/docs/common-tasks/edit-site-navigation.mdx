# Edit public site navigation

## Goal

Change the public header and Explore/footer links without editing the Astro templates.

## Who can edit

Only Studio members with **Administrator**, **Editor**, or **Developer** roles. Contributors who catalog photographs and transcriptions do not see this document and cannot publish it.

There is **one** Public site navigation document. Do not look for a Create button — the type is hidden from the global Create menu so a second copy cannot be made.

## Steps

1. Open **The Website → Public site navigation**.
2. Under **Header — always visible**, add, reorder, or remove top-bar links. Drag to change order.
3. Under **Explore, footer, and sidebars**, edit links used on the homepage Explore block, collection sidebars, and footer.
4. For each link, set **Label**, **Path** (starts with `/`), and **Kind**:
   - **Page** — a text link.
   - **Search** — the header search field. Keep **Path** as `/search` so results still have a URL. Only one Search item is allowed.
5. **Purpose** is a Studio-only reminder (for example “Volume index”). It is not shown on the public site.
6. Publish.

To drop **About** later (if the site sits under tehistory.org chrome), remove that Explore item and publish. Moving Search into Explore is an explicit drag from Header to Explore, not a hidden setting.
