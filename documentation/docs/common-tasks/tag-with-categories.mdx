# Tag with subject categories

## Goal

Use subject categories so related primary sources and images can be discovered by theme.

## Categories vs property / business types

| | Subject Categories | Property Type / Business Type |
| --- | --- | --- |
| Used on | Primary sources and historical images (**Subjects**) | Property or Business documents |
| Purpose | Themes for archive search and filters | Classify what kind of building or organisation the entity is |
| Examples | Schools, Railroads, Farms, Genealogy, Businesses, Organizations | `church`, `inn`, `railroad`; civic / commercial / institutional |
| How many | Several themes per clipping or photo | One type per property or business |

Overlapping names are intentional but different jobs: a photo about churches gets the **Churches** category; a church building gets Property Type **Church**.

## Steps

1. Ensure the category exists under **Taxonomies & Entities → Subject Categories** (create if needed: title + optional description).
2. Open a **Primary Source** or **Historical Image**.
3. In **Research → Subjects**, add references to the relevant categories (e.g. Schools, Railroads, Farms).
4. Publish when ready.

## Field notes

- Categories are broad themes from subject lists and advanced-search style filters—not free-text tags on every document.
- Prefer reusing existing category documents over creating near-duplicates.
- Do not create a category instead of setting Property Type or Business Type on taxonomy entities.
