# Tag with subject categories

## Goal

Use subject categories so related primary sources, images, and TEHS Quarterly articles can be discovered by theme.

## Categories vs property type and named entities

| | Subject Categories | Property Type | Business / Organization |
| --- | --- | --- | --- |
| Used on | Primary sources, historical images, and TEHS Quarterly articles (**Subjects**) | Property documents | Business or Organization documents |
| Purpose | Themes for archive search and filters | Classify what kind of building the site is | Name the firm or civic/institutional group |
| Examples | Schools, Railroads, Farms, Genealogy, Businesses, Organizations | `church`, `inn`, `railroad`, `industrial` | Lincoln Institution; Bean’s Lumber Yard |
| How many | Several themes per clipping or photo | One type per property | One document per named entity |

Overlapping names are intentional but different jobs: a photo about churches gets the **Churches** category; a church building gets Property Type **Church**.

To link archive material to a named business or organization (e.g. Lincoln Institution), use **Research → Organizations**, not Subjects. See [Record a business](./record-a-business.mdx) and [Record an organization](./record-an-organization.mdx).

## Steps

1. Ensure the category exists under **Taxonomies & Entities → Subject Categories** (create if needed: title + optional description).
2. Open a **Primary Source**, **Historical Image**, or **TEHS Quarterly Article**.
3. In **Subjects** (on archive items: **Research → Subjects**; on Quarterly articles: **Tagged Entities → Subjects**), add references to the relevant categories (e.g. Schools, Railroads, Farms).
4. Publish when ready.

## Field notes

- Categories are broad themes from subject lists and advanced-search style filters—not free-text tags on every document.
- Prefer reusing existing category documents over creating near-duplicates.
- Do not create a category instead of setting Property Type on a property, or instead of creating a Business or Organization document for a named entity.
