# Publish a research article

## Goal

Create a long-form website page with slug, township scope, and optional map or article-link modules.

## Steps

1. Open **The Website → Research Articles & Overviews** and create a new document.
2. Set **Page Title** and generate the **URL Slug** (both required).
3. If matching an imported Book or catalog record, set **Archive ID**—it must be unique.
4. Add **Townships** that define the research article’s geographic scope.
5. In **Context**, tag **People Mentioned** and **Organizations** (businesses and organizations) discussed in the article. Create or reuse records under Taxonomies & Entities.
6. In **Page Content & Layout Canvas**, write Portable Text content.
7. To insert an **Uploaded Image**, press Enter for a new line and use the **+** button, or type `/` and choose **Uploaded Image**. Drag the block handle to place it between paragraphs.
8. On the image settings panel, add **Caption** and **Alt Text**, then choose **Image Role**: Primary illustration or Supporting image (defaults to Primary).
9. Optionally insert an **Interactive Map Module** with historical map year and engine embed URL.
10. Optionally insert a **Nested Navigation Portal Index** linking to other research articles.
11. In **Notes & References**, add published bibliographic notes, endnotes, and web links that should appear with the article.
12. In **Internal → Internal Comments**, add private working notes (QA, sources to check, unfinished remarks). This field **will not appear on the public site**.
13. Publish when ready.

## Field notes

- Use Research Article for modern research and overviews—not for raw clipping transcriptions ([choose the right type](./choose-document-type.mdx)).
- **People Mentioned** and **Organizations** (businesses and organizations in one field) live under **Context**. Create or reuse the person, business, or organization document first.
- Image vertical order is the block order in the canvas; **Image Role** (`figure` / `aside`) is a semantic hint—Primary vs Supporting—for how the website should present the image, not raw CSS layout.
- Map modules need both a target year and an embeddable application URL for the map engine.
- In **Notes & References**, type the citation, select the title, and paste a URL to attach a link. That field is published; do not put private or unfinished notes there.
- **Internal Comments** is Studio-only and never goes on the public site. Use it for working notes that editors should see and the public should not.
