# Set Archive IDs

## Goal

Record the official internal catalog number for each imported or cataloged item so archivists can find and match records consistently.

## Where Archive IDs live

| Field | Document type | Example | Rule |
| --- | --- | --- | --- |
| **Archive ID** (`archiveId`) | Primary Source | `Doc505` | Must be unique |
| **Archive ID** (`archiveId`) | Historical Image | `MF37` | Must be unique |
| **Archive ID** (`archiveId`) | Research Article | `942` | Must be unique |
| **Archive ID** (`archiveId`) | Deed / Land Instrument | `G2-182` | Must be unique |

## Steps

1. Open the Studio document for the primary source, historical image, research article, or deed.
2. Enter the **Archive ID**—use the existing catalog number when one already exists; do not invent a new one.
3. Save; Studio validates uniqueness. Fix conflicts before publishing.

## Field notes

- Uniqueness is enforced so two documents cannot share the same Archive ID within the same document type.
- Leave the field empty only when there is no corresponding catalog number yet.
