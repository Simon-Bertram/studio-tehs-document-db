# Publish a Then & Now

## Goal

Create a Then & Now feature: two photographs of the same landmark, each with commentary. It belongs to a printed TEHS Quarterly issue and also has its own public page.

## Steps

1. Open **The Website → Then & Now** and create a new document. Or open **The Website → TEHS Quarterly Issues**, open the issue, then **Then & Now in this issue** (the Issue reference is filled in).
2. Set **Page Title** and generate the **URL Slug** (both required).
3. Tick **Show in the public highlight grid** only when this page should appear in the home research teasers. Optional **Highlight order** (1–24) is sort order, not quality.
4. In **Publication Details**, set **Issue** if it is not already filled. Add author name, start page, and optional end page when known.
5. Optionally write an **Introduction**—opening text that is not tied to either photograph.
6. In **Then**, choose **Photograph source**. Prefer **Historical Image** when the photograph is already in **The Archive → Historical Images**. Search by caption or Archive ID. Leave Caption and Alt Text blank to use the catalog caption, then write **Commentary**.
7. In **Now**, choose **Photograph source**. A contemporary photograph that is not in the archive collection can be an **Uploaded photograph**. Add **Year Taken** when known, **Caption**, **Alt Text**, and **Commentary**. If the modern photo belongs in the archive, [catalog it as a Historical Image](./catalog-historical-image.mdx) first, then choose **Historical Image**.
8. In **Context**, add **Townships** and tag **Properties / Historic Sites Mentioned** (the landmark), plus people and organizations discussed. Create or reuse records under Taxonomies & Entities.
9. In **Notes & References**, add published bibliographic notes, endnotes, and web links that should appear with the piece.
10. In **Internal → Internal Comments**, add private working notes. This field **will not appear on the public site**.
11. Publish when ready.

## Field notes

- Use Then & Now for the Quarterly landmark comparison—not a [Research Article](./publish-research-article.mdx) and not a digitized [TEHS Quarterly Article](./cite-quarterly-article.mdx) ([choose the right type](./choose-document-type.mdx)).
- **Then** and **Now** are meaning labels. The website decides whether to show the photographs side by side, stacked, or as a slider.
- Prefer **Historical Image** when the photograph is already cataloged. Upload only if it is not in that collection.
- Caption and alt text on a Historical Image source may be left blank; the catalog caption is the fallback. Add alt text for uploaded photographs.
- **Issue** is required so the piece appears in that issue’s table of contents. The slug is for the standalone public page.
- **Notes & References** is published bibliography *on this piece*. Do not put private or unfinished notes there—use **Internal Comments** instead.
- Archive items can cite this document under **Research References**, the same field used for TEHS Quarterly Articles.
