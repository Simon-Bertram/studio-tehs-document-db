# Common tasks

Day-to-day workflows for editors and archivists in TEHS Document DB.

| Task | When to use it |
| --- | --- |
| [Choose the right document type](./choose-document-type.mdx) | Before creating anything—avoid mixing transcriptions with modern essays |
| [Add a primary source / transcription](./add-primary-source.mdx) | Ingesting a clipping, letter, or other single historical text |
| [Catalog a historical image](./catalog-historical-image.mdx) | Adding a photograph with caption and provenance |
| [Record a donation](./record-a-donation.mdx) | Gift / accession records and material-type categories |
| [Link geography](./link-geography.mdx) | Placing content on township, location, or property |
| [Create and link people](./create-and-link-people.mdx) | Naming people in sources, photographs, properties, businesses, or organizations |
| [Add a family lineage](./add-family-lineage.mdx) | Family groups and person-to-person relationships |
| [Model a property or estate](./model-a-property.mdx) | Buildings, farms, and site types linked to businesses and organizations |
| [Enter a deed or land instrument](./enter-deed.mdx) | Chain-of-title conveyances linked to properties and people |
| [Record a business](./record-a-business.mdx) | Commercial / industrial firms, owners, and property sites |
| [Record an organization](./record-an-organization.mdx) | Civic, community, and institutional groups and property sites |
| [Tag with subject categories](./tag-with-categories.mdx) | Schools, Railroads, Farms, and other discovery themes |
| [Cite a TEHS Quarterly article](./cite-quarterly-article.mdx) | Bibliographic records and research references |
| [Publish a research article](./publish-research-article.mdx) | Long-form website pages with maps and article links |
| [Publish a Then & Now](./publish-then-and-now.mdx) | Quarterly landmark comparison with a standalone public page |
| [Edit public site navigation](./edit-site-navigation.mdx) | Header and Explore/footer links on the public site (editors only) |
| [Enter a sheriff’s sale source](./enter-sheriff-sale.mdx) | Sheriff’s sale notices with legal writ and property |
| [Set Archive IDs](./set-archive-ids.mdx) | Official catalog numbers (e.g. Doc###, MF##) |
