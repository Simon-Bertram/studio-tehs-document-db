# Model a property or estate

## Goal

Describe a building or land tract, including parent estates, residents, and a structured title chain.

## Property vs organization

- **Property** = the physical site or building (house, church, mill, school building).
- **Organization** = who operated or occupied it (congregation, fire company, library, water company, lumber yard). Create an [organization document](./record-a-business.mdx) and link properties under **Associated Properties / Sites** on the organization.
- Do **not** invent a property type for “organization.” Classify the *site* (usually Institutional), then link the org from the organization document.
- **Valley Forge** association = set **Specific Location** to Valley Forge. Encampment vs Industry themes come later; they are not property types.

## Property Type vs Subject Categories

- **Property Type** = building classification on this document (required; one value). Controls Studio behaviour such as hiding Parent Estate when the type is Estate / Farm.
- **Subject Categories** (e.g. Churches, Inns, Railroads) = themes for [tagging archive clippings and photos](./tag-with-categories.mdx). They are not set on properties.
- Similar names are fine: a church *building* uses Property Type **Church**; a clipping *about* churches uses the **Churches** category.

## Property types

| Title | Value | Covers |
| --- | --- | --- |
| Dwelling / House | `dwelling` | House/building; VF buildings that are residences; former tenant houses; outbuildings on a parent estate |
| Estate / Farm | `estate` | Large farms/estates (parent for houses and outbuildings); bare land tracts / former subdivision lots |
| Church | `church` | Churches |
| Inn / Tavern | `inn` | Inns |
| Industrial | `industrial` | Mills; quarries & mines; utilities / water companies; VF industry sites |
| Institutional | `institutional` | Schools; fire companies, libraries, conservancies, military/civic sites |
| Railroad / Station | `railroad` | Railroads / stations |

## Steps

1. Open **Taxonomies & Entities → Properties & Buildings** and create a new document.
2. Set **Historical Name** (required) and **Property Type** (required; see table above).
3. If this structure sits on a larger farm, set **Parent Estate / Land Tract** (hidden when type is Estate / Farm).
4. Set **Specific Location** or **Township** ([geography rules](./link-geography.mdx)). Use a Valley Forge location when the site belongs there.
5. Add structural evolution notes, notable residents, modern address, and year built.
6. Build the chain of title: create [Deed / Land Instrument](./enter-deed.mdx) documents for each conveyance, then order them under **Title Chain** on this property.
7. Link occupying organizations from the [organization document](./record-a-business.mdx) (**Associated Properties / Sites**)—not from the property.
8. Link the property from primary sources via **Associated Properties** when cataloging related notices.

## Field notes

- Example parent link: “By-The-Creek” → parent “Glenhardie Farm”.
- Former outbuildings and lots use **Dwelling / House** or **Estate / Farm** plus `parentEstate` and evolution notes—there is no separate outbuilding or subdivision-lot type.
- **Title Chain** is an ordered list of Deed documents.
