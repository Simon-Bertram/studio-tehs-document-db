# Record a donation

## Goal

Record a gift or accession and tag the material types it contains.

## Donation Categories vs Subject Categories

| | Donation Categories | Subject Categories |
| --- | --- | --- |
| Used on | **Donation** documents | Primary sources and historical images (**Subjects**) |
| Purpose | What kind of material was donated | Themes for archive search and filters |
| Examples | Photographic prints, Postcards, Slides, Posters | Schools, Railroads, Farms, Genealogy |
| How many | One or more per donation | Several themes per clipping or photo |

## Steps

1. Ensure the material types you need exist under **Taxonomies & Entities → Donation Categories** (create if needed: title + optional description). You can also create a category with **Create new** while linking from a donation.
2. Open **The Archive → Donations** and create a new document.
3. Fill in **Donation Name**, **Donation ID**, **Donation Acquisition Date**, **Donation Description**, and **Donor** as known.
4. Under **Donation Categories**, add one or more references for the materials in the gift (e.g. Photographic prints and Postcards).
5. Publish when ready.

## Field notes

- Prefer reusing existing Donation Category documents over creating near-duplicates.
- Seeded material types include Photographic prints, Digital photographs, Newspaper clipping, Postcards, Slides, Drawings, and Posters—add more only when a new material type is needed.
- Historical Images link to a Donation under Provenance / Rights. When cataloging photos from a new gift, create the Donation first, then link each image to it.
